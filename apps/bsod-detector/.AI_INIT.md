# AI Agent Init — bsod-detector

## Sub-project Scope
This directory (`apps/bsod-detector/`) is the application sub-project for the
BSOD detector component. AI agent instructions here are scoped to this
directory and its sub-directories only.

## Quick Orientation
- **host-tools/**: Bash scripts (`extract-dump.sh`, `run.sh`) that run on the
  KVM host or inside the bsod-host-tools container.
- **src/**: Python helpers for dump-header parsing and event log extraction.
- **test/**: BATS test suite — run with `bats test/` from this directory.
- **docs/**: Usage guides and troubleshooting documentation.

## Key Constraints
- Shell scripts must be ShellCheck-clean and pass `bash -n`.
- `extract-dump.sh` emits JSON to stdout; all diagnostics go to stderr.
- The container image definition lives at `image/container/bsod-detector/`.
