### Filed virtio-win issue #1629: crash dump not generated under allocation failures
- Investigation determined crash dump bypass is a reportable bug in viostor.sys (virtio-blk).
- Root cause: during crashdump mode, StorPortGetUncachedExtension fails when nonpaged pool is exhausted or physical memory is fragmented from the crash. The driver returns SP_RETURN_ERROR and no dump is written.
- Prior art: 4 similar crashdump bugs in vioscsi (BZ#1432567, #809/BZ#2118630, PR #1294, PR #1493); viostor crashdump path never audited for this class.
- Two related issues filed: (A) viostor fails Driver Verifier Low Resources in all 5 configurations, (B) crash dump mechanism bypassed in 8/8 crashes.
- GitHub issue: https://github.com/virtio-win/kvm-guest-drivers-windows/issues/1629
