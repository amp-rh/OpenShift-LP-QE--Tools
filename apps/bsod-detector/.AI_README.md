# AI Agent Instructions

## Purpose
Windows BSOD diagnostic-capture tool for OpenShift Virtualization testing. Captures post-mortem evidence (bug-check codes, crash dumps, event logs) when Windows guest VMs experience a Blue Screen of Death.

## Local Conventions
- Scripts as tooling: deterministic operations live in scripts with clear stdin/stdout contracts (prefer JSON to stdout)
- Single source-of-truth: bug-check code tables, driver mappings, and log source names come from JSON files in src/data/
- Windows-first: scripts are PowerShell (.ps1) unless there is a reason to use another language
- No hardcoded duplicated data across scripts
- Build artifacts (*.sys, *.exe) are git-ignored and rebuilt from source

## Notes
- Detection is implicit: catches ANY bug-check code via WER System/1001 event
- src/data/trigger-methods.json defines 19 codes deliberately exercised in CI via a KeBugCheckEx test driver
- The KVM test harness (vm/) is Linux-host-side; the tool itself is Windows-guest-side
- Driver Verifier ON in test VMs changes some bug-check outcomes; data files record codes as observed
- Crash dumps may contain host-identifying data; never commit captured dumps (output/ is git-ignored)
