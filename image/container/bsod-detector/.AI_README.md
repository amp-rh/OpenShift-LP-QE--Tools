# AI Agent Instructions
## Purpose
This subdirectory contains the container image definition (Dockerfile and
Makefile) for the bsod-host-tools container.

## Local Conventions
- The Dockerfile build context is `apps/bsod-detector/` (three levels up).
- `make build` builds the image; `make push` pushes to the registry.
- `make test` runs the BATS test suite from the app directory.
- The `validate` target is a pre-flight check for CI variable overrides.

## Notes
- The image is based on `fedora-minimal` and bundles libguestfs for offline
  NTFS access to Windows guest disk images.
- `python-evtx` is pinned to a specific version for reproducible builds.
- `SHELL ["/bin/bash", "-c"]` is set explicitly for portability.
