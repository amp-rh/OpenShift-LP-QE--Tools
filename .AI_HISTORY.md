## 2026-10-07
### Fix .evtx File Extraction: Two-Phase Write Approach
- **Problem Identified**: Files were logged as "extracted" but didn't exist on disk
- **Root Cause**: Output redirection from `guestfish download file -` (stdout) through `oc exec` was failing
- **Solution**: Implemented two-phase extraction approach:
  1. **Phase 1**: guestfish writes directly to pod's /tmp using `download /path/to/file /tmp/outfile`
  2. **Phase 2**: Copy file from pod to host using `oc cp pod:/tmp/outfile /host/path`
- **Benefits**: Bypasses shell output redirection issues, more reliable file transfer, clearer error handling
- **Implementation**: Updated `ExtractNTFSFile()` function with pod-temp-file approach and oc cp
- **Verification**: Added logging for both extraction and copy phases to track file movement
